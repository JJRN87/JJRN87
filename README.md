## Museo CMS

Mi proyecto final de DAM, realizado entre tres compañeros en 2026. Es una aplicación para que artistas puedan configurar y publicar su portfolio.

Me encargué del frontend con React y Vite, del panel de administración y de conectarlo con la API REST. También trabajamos entre los tres en el modelo de datos, las pruebas y la documentación. El proyecto utiliza Spring Boot, PostgreSQL, Docker y JWT.

La entrega académica permite registrarse, iniciar sesión, editar los datos básicos del sitio y ver una página pública. Quedaron pendientes la gestión completa de obras y el almacenamiento persistente de imágenes.

[Ver el repositorio del equipo](https://github.com/andresBella96/museo-cms) · [Leer la memoria del proyecto](https://github.com/JJRN87/Proyecto_Museo_Memoria_DAM.pdf/blob/main/Cuarta_Entrega_Final.pdf)

## Olist Analytics · Power BI

Proyecto personal de Power BI con datos públicos de comercio electrónico. El informe incluye cuatro páginas: ventas, entregas, satisfacción y calidad del dato.

He trabajado la preparación de datos con Power Query, el modelo y las medidas DAX, y las comprobaciones de calidad. El repositorio incluye el archivo PBIX, capturas, un diccionario de métricas y documentación de la práctica individual con Jira y Confluence.

## GasHunter · Android y datos públicos

App para comparar precios de carburantes y localizar opciones cerca de una zona o ruta. Combina mapas, filtros y datos públicos de MITECO. El proyecto incluye un catálogo de recarga con preparación y comprobaciones de datos en Python y actualización mediante GitHub Actions.

He definido las funcionalidades, priorizado cambios y probado el funcionamiento. La implementación y parte de la documentación se han realizado con apoyo de IA.

Está en **prueba cerrada de Google Play**; la publicación general está pendiente. El código sigue privado, pero se pueden ver capturas y una explicación del proyecto.

[Ver GasHunter y sus capturas](https://jjrn87.github.io/LandingJJRN/gashunter.html)
